## 1. hh.ru: инструкция на возврат

**Где остановились.** Анонимный доступ к `api.hh.ru/vacancies` закрыт: `403 forbidden`.
Проверено двумя способами с одного IP — через curl и через обычный браузер,
ответ одинаковый, значит дело не в клиенте. Документация подтверждает:
«Если не передан токен авторизации, то после первого запроса будет предложено пройти капчу».
Приложение зарегистрировано на dev.hh.ru **14.10.2026**, ждёт модерации.

Это блокирует 9 строк реестра — все `status: blocked, blocked_by: hh_token`.

**Когда заявку одобрят, по шагам.**

1. Забрать `client_id` и `client_secret` на https://dev.hh.ru/admin

2. Получить токен приложения:

   ```powershell
   $t = (Invoke-RestMethod -Method Post "https://api.hh.ru/token" -ContentType "application/x-www-form-urlencoded" -Body @{grant_type="client_credentials"; client_id="ВАШ_CLIENT_ID"; client_secret="ВАШ_CLIENT_SECRET"}).access_token; "токен получен, длина $($t.Length)"
   ```

3. Прогнать все девять работодателей:

   ```powershell
   foreach ($id in 3202190,1062788,567799,3833791,2287613,668019,2381,238354,4105707) { try { $r = Invoke-RestMethod "https://api.hh.ru/vacancies?employer_id=$id&per_page=1" -Headers @{"Authorization"="Bearer $t"} -UserAgent "trendwatcher/1.0 (kostik80_80@mail.ru)"; "{0}`t{1}`t{2}`t{3}" -f $id, $r.found, $r.items[0].employer.name, $r.items[0].published_at } catch { "{0}`tОШИБКА: {1}" -f $id, $_.Exception.Message } }
   ```

4. Сверить: `found` похож на число вакансий на странице работодателя,
   `employer.name` — ожидаемая компания. Названия уже сверены глазами 14.10.2026,
   так что расхождение здесь означало бы проблему с запросом, а не с id.

5. Положить токен в переменную окружения `HH_APP_TOKEN`, перевести девять строк
   реестра в `status: ok`.

**Чего не делать.**

- Не вызывать `/token` из парсера на каждом прогоне: повторный запрос **отзывает**
  прежний токен. Срок жизни у него неограниченный, получать нужно один раз руками.
  Ограничение — не чаще раза в 5 минут.
- Не вписывать `client_secret` в код и не коммитить его.
- Не пытаться обойти 403 подстановкой браузерного User-Agent. Проверено, что
  браузер получает тот же отказ, а если бы и работало — такой обход отваливается
  молча, и вы узнаете об этом по пустой сводке.

**Если заявку отклонят.** Сноска на форме регистрации предупреждает, что поддержка
API для соискателей прекращена 15.12.2025. Поиск вакансий в спецификации
по-прежнему числится среди методов приложения, но если модерация ответит, что
`/vacancies` для такого приложения недоступен, — вакансии придётся брать
со страниц работодателей на самом hh.ru, и это другой объём работы.
